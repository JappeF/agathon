# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Agathon: an offline-first PWA (React 18 + TypeScript + Vite + vite-plugin-pwa) for Mage: The Ascension 20th Anniversary (M20). All decisions and the build order are in `BRAINSTORM.md` (Dutch); read it before adding features.

The app is a helper and sounding board, not a rules engine: dice are rolled outside the app. The core is a searchable library of magick effects (own summaries, never book text), character sheets imported from Mr. Gone PDFs, and spell dossiers that produce a copyable "context pack" prompt for any AI. App language is English.

## Commands

```sh
npm run dev      # Vite dev server (localhost:5173)
npm run build    # tsc -b && vite build -> dist/ (also regenerates the service worker precache)
npm run preview  # serve dist/ on localhost:4173
npm run deploy   # build + wrangler pages deploy dist --project-name agathon
npm run icons    # public/icons/sigil.svg -> PNG app icons via sharp

node scripts/verify.mjs        # headless-Edge checks: shell, nav, IndexedDB persistence, SW, offline reload, desktop nav
node scripts/verify-sheet.mjs  # import the sample Mr. Gone PDF via the UI, trackers, edit mode, PDF export round trip, re-import diff
node scripts/verify-library.mjs  # Sphere bar and exact combinations, operators, tags, detail with difficulty and checklist, deep links, castable + one dot away
node scripts/verify-share.mjs  # share link, QR, file without notes, import on a second browser context, name clash, damaged link, back up all
BASE=https://agathon.pages.dev node scripts/verify.mjs   # same checks against the live site

node scripts/sigil.mjs         # regenerate public/icons/sigil.svg (seeded sparking portal ring), then npm run icons
node scripts/build-mrgone-map.mjs <sheet.pdf>   # regenerate src/sheets/mrgone-m20-2page.json from a Mr. Gone sheet
node scripts/sheet-words.mjs <sheet.pdf>        # dump a sheet's printed words with positions (pdf.js), for building maps
```

`verify-sheet.mjs` needs the sample sheet in `refs/` (gitignored); override with `SHEET=<path>`.

The effect library (563 effects from M20 and How Do You DO That, our own summaries with book/page refs) lives in `library/`; `library/README.md` has the schema, authoring rules and counts. Edit `library/src/*.json`, then:

```sh
node library/scripts/extract-text.mjs   # once: book text into refs/text (gitignored)
node library/scripts/build.mjs          # src/*.json -> library/effects.json (committed)
node library/scripts/check.mjs          # must end in "OK: 0 issues"
```

No unit tests or linters; verify scripts (playwright-core driving system Edge via `channel: 'msedge'`) are the verification story. The preview server must be running on :4173 first.

## Architecture

- **Storage:** everything the player owns lives in IndexedDB via Dexie (`src/db/db.ts`): `characters`, `spells`, `books` (page text of the player's own rulebook PDFs, never shipped or shared). `requestPersistence()` asks for persistent storage on the first real write. Use `useLiveQuery` (dexie-react-hooks) in components.
- **Routing:** hash routes in `useHashRoute.ts`: `#/library`, `#/spells`, `#/characters`, `#/characters/<id>/<tab>` (tabs magick, traits, background, notes). `activeCharacter.ts` remembers the last opened character (localStorage) for the library and spells.
- **Characters:** `character.ts` is the full M20 model (all Attributes/Abilities in `traits`, Spheres, the Q/P wheel, health marks, backgrounds, merits/flaws, rotes, focus, wonders, description, gear, weapons, notes). `clampWheel` enforces M20 p. 331: Paradox cancels Quintessence where they meet, Quintessence stops at the Paradox. `CharacterSheet.tsx` keeps a local copy and debounces writes; play mode only lets the trackers change (health, Willpower spent, Q/P), the lock button switches to edit mode.
- **Sheet import/export:** `src/sheets/mrgone.ts` reads and writes Mr. Gone's fillable M20 2-page sheet with pdf-lib (lazy-loaded). Its dot checkboxes have meaningless names, so `mrgone-m20-2page.json` (generated by `scripts/build-mrgone-map.mjs` from field positions next to the printed labels; all 625 fields mapped, none twice) says which field is which trait. A lone `x` after a Sphere marks the affinity Sphere. The imported PDF is kept per character in the `sheetFiles` table so "Export PDF sheet" fills that same file; characters made in the app pick a blank sheet once. Re-importing shows `diffSheet` changes first and keeps id, notes and spells (`sheetActions.ts`). Matching on import is by character name.
- **Library UI:** `src/library/data.ts` lazy-loads `library/effects.json` as its own chunk (precached). `src/library/search.ts` parses the query: text, quoted phrases and `-exclusions`, Sphere operators (`mind:3` = up to 3, `=3`, `3+`, `2-4`; any 3+ letter prefix; `data:`/`primal:`/`dimsci:`), `uses:` (these Spheres plus others), `tag:`, `book:`, `kind:`, `is:`, `name:`. A Sphere query matches a combo with exactly those Spheres unless `uses:` or "Allow other Spheres" is on. With "What <character> can cast" on, hits are split by `deficit` (dots missing over the closest combo): castable now, and a separate "One dot away" section. The Sphere bar and tag chips just rewrite the query text, so the query stays the single source of truth. `EffectDetail.tsx` shows the combos (pick one), the base difficulty from M20 p. 501 (highest Sphere +3 / +4 / +5), the book's coincidental note and a mitigation checklist; Sphere tricks in it only light up when the active character has the dots. Routes: `#/library/<effect id>`; closing goes back only when the detail was opened from the list, so deep links never leave the app.
- **Portraits:** `portrait.ts` turns any image into a 384px square data URL (WebP, JPEG fallback for old Safari), cropped a little above centre. On PDF import the largest JPEG that is not a full-page background or a thin strip is taken as the portrait (`portraitFromPdf`, pdf-lib); it only fills an empty portrait, never replaces one set in the app, because `portrait` is app-owned and left out of `SheetFields`/`diffSheet`. Shares carry it in files but not in links/QR codes (size); incoming ones pass `safePortrait`. `PortalPortrait.tsx` draws it inside a small sparking portal: a CSS ring and glow (cheap for lists) plus the shared `makeSparks`/`SparkLines` from `Portal.tsx`.
- **Sharing:** `share.ts` is the versioned wire format (`app: 'agathon', kind: 'characters', version: 1`), as a `.agathon.json` file or a `#import=<mode>.<base64url(deflate-raw(json))>` link/QR (empty values are dropped to keep links short). Everything from outside goes through `sanitizeCharacter` (known fields only, values clamped) before it touches the database. Shares never carry ids, timestamps or the stored PDF; notes only when ticked. `App.tsx` turns `#import=` links into the `SharedImport` preview; imports only add, a clashing name gets " (2)". The Import button takes both PDFs and character files.
- **Modals** render through a portal on `<body>` (`Modal.tsx`), so a dialog opened from inside the `<details>` menu survives the menu closing.
- **PWA:** `registerType: 'prompt'`; `UpdateToast.tsx` (mounted in main.tsx outside App) re-checks hourly and on focus and shows a Reload toast. Its reload falls back to `location.reload()` when the page was never controlled by the service worker (first visit), because `updateServiceWorker(true)` only reloads on a controller change. `public/_headers` keeps index.html/sw.js/workbox/manifest uncached on Cloudflare.
- **Rulebooks and samples** live in `refs/` (gitignored, never commit them or text extracted from them). Only our own summaries are committed.

## Design system

App icon: a sparking golden portal ring (in the spirit of Doctor Strange's portals) on dark violet with a dark violet heart, sparks flying off clockwise, generated by `scripts/sigil.mjs`. The same portal lives, animated, behind the logo (`Portal.tsx`). Violet depths and gilded type in `src/styles.css`: gold `--gold` on violet-black `--bg`, `--paradox` magenta for Paradox. Fonts self-hosted via fontsource: Cinzel Decorative (logo only), Cinzel (headings), Manrope (UI text), EB Garamond italic (flavor text and quotes only). Animations are CSS-only and switched off under `prefers-reduced-motion`: rising gold Quintessence sparks (`.sparks`), the gilded logo sheen, and the header portal (breathing glow, a glint running clockwise every 9s, seeded sparks flying off clockwise). `SphereGlyph.tsx` holds our own line glyphs per Sphere (Entropy a spiral breaking into shards, Mind a brain, Prime a trident over a flared cross, Spirit a little ghost; not the book symbols); reuse it for Sphere chips. Mobile first: bottom nav below 768px, sticky pill nav above; tap targets at least 44px.

## Gotchas

- `all: unset` on buttons resets `box-sizing`; re-set it after (as in `.btn-icon`).
- Shipped text uses plain keyboard characters only: no em/en dashes, no curly quotes (house style, same as another app).
- Commit messages end with a line containing only `⚡`, no other trailers.
- Hosting is a classic Cloudflare Pages project (`agathon`, live at https://agathon.pages.dev), created with the hidden `wrangler pages project create --force` flag. Without it, wrangler 4.151 silently "delegates" new Pages projects to Workers: it rewrote package.json scripts (`wrangler dev`/`wrangler deploy`), added `@cloudflare/vite-plugin` to vite.config.ts and a `wrangler.jsonc`, and deployed a Worker on workers.dev. Now that the project exists, `npm run deploy` (`wrangler pages deploy`) goes straight to Pages; never run `wrangler deploy` here or accept that conversion, and do not pass `--force` again.
- The GitHub repo `OWNER/agathon` is private for now.
